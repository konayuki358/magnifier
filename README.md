# 拡大鏡 (無料・広告なし)

AndroidのChromeで動く、カメラを利用した拡大鏡です。カメラ映像の送信・保存、広告、外部通信、会員登録はありません。ページを初回読み込みする際の通信（GitHub Pagesへのアクセス）は必要です。

## 主な機能
- 背面カメラを自動起動（初回はカメラ許可が必要）
- 2本指ピンチ、スライダーで1.0〜8.0倍に拡大
- 対応機種ではカメラのズームを優先。非対応の場合は映像を拡大（画質に限界あり）
- 対応機種ではライトを操作
- 映像の一時停止・再開（静止画像は端末内メモリのみに保持）
- ホーム画面に追加できるPWA

## GitHub Pagesで公開する
1. `konayuki358` でGitHubにログインする。
2. 新しいPublicリポジトリを `magnifier` という名前で作る。
3. このZIPを展開し、`index.html` などのファイルと `icons/` フォルダをリポジトリ直下にアップロードする（ZIPそのものだけを置いても動きません）。
4. リポジトリの `Settings > Pages` で `Deploy from a branch`、`main`、`/(root)` を選択して保存する。
5. 公開URL `https://konayuki358.github.io/magnifier/` をAndroid Chromeで開く。初回はカメラの許可が必要。
6. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。

## 必ず確認すること
- AndroidスマートフォンのChromeで背面カメラが映るか
- 初回のカメラ使用許可／拒否後の再試行
- ピンチ操作とスライダーが機能するか
- ライトのON/OFF（対応端末のみ）
- 一時停止後に再開できるか
- ホーム画面アイコンで起動できるか

## 注意事項
- カメラはHTTPSまたは `localhost` などの安全なオリジンでのみ利用できます。`file://` でHTMLを直接開いた場合は動作しないことがあります。
- ブラウザや端末によってライト・光学ズームは未対応です。その場合ライトは無効化され、映像側のデジタル拡大になります。
- 公開リポジトリはソースコードを誰でも閲覧できます。本人の名前やメールアドレスをコミット作者情報、README、プロフィールなどに含めないでください。
- 拡大鏡は小さな文字を確認する補助ツールであり、視力や老眼そのものを治すものではありません。
